## 一、AI 运营到底是干什么的

### 一句话定义
AI 运营 = 用运营的方法，把 AI 产品/功能推给用户，让用户用起来、留下来、付钱。

### 和传统运营的区别
| 维度 | 传统运营 | AI 运营 |
|---|---|---|
| 核心载体 | 商品/内容/活动 | AI 产品/AI 功能/AI 内容 |
| 用户沟通 | 人工客服 / 社群 | AI 助手 + 人工兜底 |
| 内容产出 | 小编写 / UGC | AIGC + 人工审核 + 模板化 |
| 数据驱动 | 看 UV/PV/转化率 | 多了"对话轮次""任务完成率""AI 准确率"等新指标 |
| 核心能力 | 内容感 + 活动策划 + 用户洞察 | 以上 + 对 AI 能力边界的理解 + Prompt 思维 |

### 常见岗位细分
1. **AI 产品运营**：负责 AI 产品的用户增长、留存、功能迭代
2. **AIGC 内容运营**：用 AI 工具产出内容（文案/图片/视频），运营账号或内容平台
3. **AI 增长/投放运营**：用 AI 优化投放策略，做用户获取和转化
4. **AI 用户运营 / 社群运营**：AI 产品的用户社群、用户反馈收集
5. **AI 解决方案 / FDE**：帮客户部署和使用 AI 产品，偏售前+实施

## 二、必须知道的运营基础概念

### 核心指标（AARRR 漏斗）
- **Acquisition 获客**：用户从哪来？渠道有哪些？获客成本（CAC）多少？
- **Activation 激活**：用户第一次感受到产品价值（"啊哈时刻"）
- **Retention 留存**：用户会不会回来？次日留存/7日留存/30日留存
- **Revenue 收入**：用户愿不愿意付钱？付多少？（ARPU、LTV）
- **Referral 推荐**：用户愿不愿意推荐给别人？

### 常见运营术语
| 术语 | 意思 |
|---|---|
| UV | 独立访客数（Unique Visitor） |
| PV | 页面浏览量（Page View） |
| CTR | 点击率（Click Through Rate）= 点击数 / 曝光数 |
| CVR / 转化率 | 转化人数 / 访问人数 |
| ROI | 投入产出比（Return On Investment）= 收入 / 投入 |
| DAU / MAU | 日活 / 月活用户数 |
| 留存率 | 第 N 天还回来的用户比例 |
| LTV | 用户生命周期总价值（Life Time Value） |
| CAC | 获客成本（Customer Acquisition Cost） |
| A/B 测试 | 两个版本对比，看哪个效果好 |
| Push | 推送通知（App 推送 / 短信 / 邮件） |
| 资源位 | App 或网站上的广告位、推荐位 |
| 落地页 / Landing Page | 用户点击广告后到达的页面 |
| 私域 | 自己能直接触达的用户池（微信群、公众号、企微等） |

### AI 产品特有的指标
- **对话轮次**：用户和 AI 聊了多少轮
- **任务完成率**：用户用 AI 完成目标任务的比例
- **AI 准确率 / 幻觉率**：AI 回答的正确率（需要人工标注）
- **采纳率**：用户采纳 AI 建议的比例
- **Prompt 使用量**：某些功能被调用了多少次

## 三、AI 大模型基础常识

### 常见大模型厂商（国内）
- **阿里**：通义千问（Qwen）
- **字节**：豆包（Doubao）/ 扣子（Coze）
- **百度**：文心一言
- **腾讯**：混元
- **月之暗面**：Kimi
- **MiniMax**：ABAB 大模型
- **智谱**：GLM
- **DeepSeek**：深度求索

### 常见概念
- **大语言模型（LLM）**：能理解和生成人类语言的 AI 模型
- **Prompt / 提示词**：你给 AI 的指令，决定了 AI 输出的质量
- **Agent / 智能体**：能自己规划、调用工具、完成复杂任务的 AI
- **RAG**：检索增强生成，让 AI 基于指定资料回答问题
- **微调（Fine-tuning）**：用特定数据进一步训练模型，让它更擅长某个领域
- **幻觉（Hallucination）**：AI 一本正经地胡说八道，编造事实
- **Token**：AI 处理文本的基本单位（大概 1 个汉字 ≈ 1-2 个 token）
- **上下文窗口**：AI 一次能记住的对话/文本长度

### AI 能做什么（运营场景）
- 文案生成（标题、正文、广告语）
- 图片生成（海报、素材、配图）
- 数据分析（给数据让 AI 分析结论）
- 用户客服（AI 客服 + 人工兜底）
- 内容审核（AI 初审 + 人工复审）
- 个性化推荐（基于用户行为推荐内容/产品）

### AI 不能做什么（现阶段）
- 不能保证 100% 准确（幻觉问题）
- 不能完全替代人工做创意决策
- 不能处理需要实时、强逻辑推理的复杂问题
- 不能绕过平台规则（该违规还是违规）

## 四、AI 运营岗位的真实门槛

### 入门级（外包/小公司，6-10K）
- 会用 AI 工具（豆包、Midjourney 等）
- 有基础运营能力（内容、活动、社群任选其一）
- 会 Excel 基本操作
- 学习能力强，愿意折腾新工具

### 进阶级（中型公司，12-20K）
- 有独立负责过一个项目/渠道的经验
- 会数据分析（Excel 透视表 + 基础 SQL 加分）
- 理解 AI 产品的能力边界
- 能写 Prompt，能用 AI 提效
- 有投放/增长经验加分

### 高级（大厂/高潜，20K+）
- 有完整的从 0 到 1 经验
- 懂用户增长方法论
- 能跨部门协调推进项目
- 数据驱动决策能力强
- 对 AI 行业有深度理解

## 五、转行 AI 运营的可迁移能力

| 你以前的经验 | 可以迁移到 AI 运营的能力 |
|---|---|
| 化工/实验 | 数据记录、变量控制、实验设计 → A/B 测试、数据分析 |
| 销售/客服 | 客户沟通、需求理解、转化 → 用户运营、增长转化 |
| 行政/HR | 协调推进、文档、流程 → 项目运营、流程优化 |
| 教育/培训 | 内容、讲解、学员管理 → 内容运营、用户社群 |
| 新媒体/文案 | 内容创作、选题、账号运营 → AIGC 内容运营 |
| 设计/美术 | 视觉审美、素材制作 → AI 绘图 + 运营素材 |
| 任何需要 Excel 的工作 | 数据整理、报表 → 运营数据分析 |

> 关键不是你以前做什么，而是你能不能把以前的经历"翻译"成新行业听得懂的语言。
> 详见：`resume-jobhunt` 技能的翻译模式。

## 六、入行路径（现实版）

### 路径 A：外包 → 正式 → 更高（最稳）
```
大厂外包AI运营(6-10K) → 小公司正式运营(10-15K) → 中型投放/增长岗(15-25K) → 大厂/高潜(25K+)
```
- 优点：门槛低，能快速入行，攒大厂履历
- 缺点：外包稳定性差，学东西靠自己
- 适合：存款紧张、需要尽快入行的人

### 路径 B：副业 → 跳槽（最安全）
```
在职做AI副业账号/项目 → 攒作品集 → 跳正式岗
```
- 优点：风险低，有作品再跳，薪资谈得更高
- 缺点：周期长，需要自律
- 适合：在职转行、有一定存款的人

### 路径 C：培训 → 就业（不推荐）
```
报班学 → 找工作
```
- 缺点：培训贷多、质量参差不齐、学完还是没经验
- 警惕：说"包就业""保底薪"的基本都是坑

## 七、避坑清单

### 求职避坑
1. **培训贷陷阱**：让你先交钱培训、说包就业的，100% 是坑
2. **挂羊头卖狗肉**：写着"AI 运营"，实际是纯销售/电话销售
3. **JD 注水**：写着"主导大促""负责增长"，实际就是配置优惠券、换 banner
4. **薪资虚高**：写 15-25K，实际只能拿到 10K（薪资区间看下限就对了）
5. **纯外包驻场**：完全做杂活，学不到东西，待久了简历贬值

### 学习避坑
1. **别囤课**：买 10 门课不如动手做 1 个项目
2. **别只学工具**：AI 工具更新很快，核心是运营思维 + AI 思维
3. **别迷信证书**：行业不认什么"AI 运营证书"，看作品和经验
4. **别脱离实战**：学了就要用，做账号、做项目、做作品集

## 八、学习路线（入门 3 个月）

### 第 1 个月：打基础
- AI 工具实操：豆包/通义千问、Midjourney/即梦，每天用 1 小时
- 运营基础：搞懂 AARRR、UV/PV、CTR、转化率这些基本概念
- 行业认知：关注 3-5 个 AI 行业公众号/博主，每天刷 30 分钟

### 第 2 个月：做项目
- 选 1 个方向做实操项目（小红书 AI 工具号 / AI 文案工具 / 数据标注小系统）
- 目标：产出 1 个能写进简历的作品（有交付物、有数据更好）
- 同时练 Excel：透视表、VLOOKUP、常用函数

### 第 3 个月：找工作
- 改简历：把旧经历 + 新项目翻译成 AI 运营语言
- 投递：海投 + 精准投结合，每周至少投 20 份
- 面试备战：每面完立刻复盘，把面试题记到知识库
