### Week 3-4：内容运营 + AI 提效

#### 📝 Prompt 工程基础

Prompt（提示词）是你和 AI 沟通的语言。写好 Prompt 是 AI 运营的核心技能。

**基础框架：CREATE 模型**

| 元素 | 说明 | 示例 |
|---|---|---|
| **C** - Context（背景） | 告诉 AI 你是谁、在做什么 | "我是转行做 AI 运营的新手" |
| **R** - Role（角色） | 给 AI 设定专家身份 | "你是一位 5 年经验的小红书爆款文案策划" |
| **E** - Example（示例） | 提供你想要的风格参考 | "参考这种风格：'原文…'" |
| **A** - Ask（任务） | 明确告诉 AI 要做什么 | "写一篇关于 AI 工具的小红书种草笔记" |
| **T** - Tone（语气） | 指定输出风格 | "语气像闺蜜聊天，接地气，多用 emoji" |
| **E** - Extra（补充） | 额外约束或要求 | "控制在 500 字以内，包含 3 个卖点" |

**高级技巧：**
- **分步拆解**：复杂任务拆成多轮对话，不要一次性要求太多
- **迭代优化**：先让 AI 出初稿，再针对性调整（"把第二段改得更口语化"）
- **反向 Prompt**：让 AI 帮你写 Prompt（"帮我写一个写小红书笔记的提示词"）
- **Few-shot 示例**：给 2-3 个好例子，AI 模仿起来更准确

**常见错误：**
| ❌ 错误 | ✅ 正确 |
|---|---|
| "帮我写篇文章"（太模糊） | "帮我写一篇关于 AI 工具的小红书笔记，目标读者是想转行的 25-30 岁打工人，400 字左右" |
| 一句话塞 5 个要求（太复杂） | 拆成 2-3 轮对话，先出初稿再调整 |
| 拿到第一版就用（不迭代） | 通常需要 2-3 轮调整才好用 |

#### 🔥 文案生成实战 Prompt 模板（直接抄）

**小红书种草笔记：**
```
你是一位小红书爆款笔记创作者，擅长写 AI 工具种草内容。

请帮我写一篇关于【工具/主题】的小红书笔记：

- 人设：28 岁转行做 AI 运营的普通人
- 语气：真实分享，像跟闺蜜聊天，不装
- 必须包含：吸睛标题 + 开头痛点共鸣 + 使用体验（3 个亮点）+ 适用人群 + 总结推荐
- 加入适当的 emoji（不要过度）
- 字数 400-600 字
- 标签 5-8 个
```

**公众号长文：**
```
你是一位 AI 领域的资深内容创作者，有 3 年经验。

请帮我写一篇关于【主题】的公众号文章。

要求：
- 目标读者：想转行 AI 的传统行业从业者
- 文章长度：1500 字左右
- 风格：干货 + 故事感，不说教
- 结构：提出痛点 → 分析原因 → 给出 3 个方法 → 总结升华
- 包含 2 个真实案例或数据支撑
- 标题提供 3 个选项供我选择
```

**标题批量生成：**
```
我写了一篇关于【主题】的文章，核心观点是【一句话总结】。

请帮我生成 20 个标题，覆盖以下类型各 4 个：
1. 数字型："5 个方法让你…"
2. 疑问型："为什么…"
3. 反常识型："…其实是个误区"
4. 痛点型："还在…？试试…"
5. 情绪型（共鸣/焦虑/希望）
```

**短视频脚本：**
```
你是一位抖音短视频编导。

请帮我写一个 30 秒的短视频脚本，主题是【主题】。

格式要求：
| 时间 | 画面 | 口播台词 | 字幕/备注 |
|------|------|---------|----------|

- 前 3 秒必须有强钩子（提问/反常识/冲突）
- 整体节奏紧凑
- 结尾有明确的互动引导（关注/评论）
```

#### 🎨 AI 绘图入门

**AI 生图工作流：**
```
需求确认 → 描述拆解 → Prompt 编写 → 生成测试 → 迭代调整 → 后期微调
```

**小红书封面 Prompt 模板：**
```
小红书封面图，【主题】，
大字标题文字："【标题文字】",
简约风格，【主色调】色背景，
干净清爽，高分辨率，3:4 竖版
```

**常用参数：**
- `--ar 3:4` 竖版（小红书封面）
- `--ar 16:9` 横版（公众号头图）
- `--ar 1:1` 方形（商品主图/朋友圈）

### 📈 运营核心指标速查表

**内容运营：**
| 指标 | 含义 | 健康值参考 |
|---|---|---|
| 曝光量 | 内容被看到的次数 | 因平台和账号阶段而异 |
| 点击率(CTR) | 看到后点击的比例 | 小红书 >5%, 公众号 >2% |
| 互动率 | (点赞+评论+收藏)/曝光 | >3% 为优 |
| 收藏率 | 收藏/曝光 | >2% 为优（干货内容） |
| 完读率 | 看完文章的比例 | >30% 为优 |

**用户运营：**
| 指标 | 含义 | 关注重点 |
|---|---|---|
| 新增用户 | 新增关注/注册数 | 增长趋势 |
| 留存率 | 次日/7日/30日留存 | 次留 >30% |
| 转化率 | 完成目标行为比例 | 因目标而异 |
| LTV | 用户生命周期总价值 | LTV > CAC |

**投放运营：**
| 指标 | 含义 | 关注重点 |
|---|---|---|
| CPM | 千次曝光成本 | 越低越好 |
| CPC | 单次点击成本 | 行业对比 |
| CTR | 点击率 | 高于行业均值 |
| CAC | 获客成本 | LTV/CAC > 3 |
| ROI | 投入产出比 | >1 为正 |

## 💡 学习心法

### 5 条核心原则

**1. 边学边做，不做囤课党**
> 学一个用法就立刻用在你的账号/项目里。解决一个真实问题 > 看十篇教程。

**2. 从痛点切入，不追求全面**
> 你现在最缺什么？先解决那个。见效了再扩展。不要一上来就想"系统学习"。

**3. 建立个人 Prompt 库，这是你的核心资产**
> 好的提示词越用越精炼。持续积累，形成自己的"AI 操作系统"。

**4. 先精通 1-2 个场景，再横向扩展**
> 不要什么都想试试。先把文案生成练到熟练，再学下一个。

**5. 输出倒逼输入**
> 学了什么就发什么（小红书/朋友圈）。教别人是最好的学习方式，还能顺便攒作品。

---

### 转行常见误区

| 误区 | 真相 |
|---|---|
| "AI 什么都能做，学了 AI 就无敌了" | AI 是工具，不是替代品。判断力和业务理解仍然在你。 |
| "学完 3 个月就能拿高薪" | 第一份大概率是入门档，是跳板不是终点。别预期太高。 |
| "要用最贵的工具才专业" | 免费工具已经足够入门。核心是方法论，不是工具贵贱。 |
| "要先学 Python 才能做 AI 运营" | 大部分 AI 运营岗位不需要写代码。先补运营和 AI 思维，Python 后面再学也不迟。 |
| "我零基础，肯定比不过科班的" | 你有旧行业经验 + 转行决心，这是差异化武器。运营岗更看重实战和结果，不看专业出身。 |
| "学完再找工作，准备充分了再投" | 永远没有"完全准备好"的一天。边学边投，面试反馈是最好的学习方向。 |
| "投了几份没回音，我不行" | 转行求职的回复率本来就低（5-10% 是正常的）。投 100 份有 5-10 个面试就算成功。 |

## 现实检验（不是泼冷水，是真话）

- 这个计划是**入门路径**，不是保证就业路径。学完能达到"入门级运营岗"的要求，不是"高级运营"
- 第一份工作大概率是外包或小公司，薪资不会很高——这是跳板，不是终点
- 市场行情随时在变，计划要根据实时招聘情况调整
- 转行最需要的不是知识，是**执行力和心态**——坚持 3 个月的人，已经赢过 90% 的人了
- 有志者事竟成。放弃只需要一瞬间，但咬牙坚持走下去，你终将遇见更强大的自己。
