# Profession-ez · 转行陪跑技能包

> 给想转行的普通人，一套从"该不该转"到"接不接 offer"的全链路陪跑技能包。
> 不挑行业、不挑起点，**方法对 + 过程对 = 结果一定对**。

## 这是什么

Profession-ez 是一组供 AI 助手（TRAE / 扣子 / Dify / Codex 等支持 Skill 的环境）加载的技能文件。它不是一个网站，也不是一个 App，而是一套**工作流程 + 知识库模板 + 防幻觉规则**，让 AI 变成一个靠谱的转行陪跑员。

**核心逻辑**：先扒 15+ 真实 JD 搞清楚企业要什么，再结合你的背景定制学习计划和简历。不靠 AI 的记忆瞎编，一切用市场需求说话。

它覆盖转行的完整链路：

```
想转行 → 该不该转 → 学什么做项目 → 改简历投递 → 面试备战 → 表达训练 → 谈薪 → 评估 offer
   ①          ①           ①            ②          ③         ④        ⑤        ⑤
```

## 五个技能

| 技能 | 干什么 | 什么时候用 |
|---|---|---|
| ① 转行门 `career-transition-gate` | 行业真相核查、JD 市场调研、动机深挖、现实检验作业、可行性评估、知识点补全、实操项目设计 | 刚想转行，或纠结要不要辞职 |
| ② 简历优化 `resume-jobhunt` | 把旧行业经历翻译成新行业语言，对着 JD 精准匹配，规划投递渠道 | 准备投简历 |
| ③ JD 备战 `jd-interview-prep` | 核查 JD 真实性、补知识缺口、模拟面试、面试复盘 | 收到面试邀请 / 刚面完 |
| ④ 表达训练 `expression-coach` | 点评回答和提示词的毛病，STAR 故事库，紧张管理 | 想练表达 / 随时可嵌入其他技能 |
| ⑤ Offer 评估 `offer-evaluator` | 谈薪策略、真实到手测算、六维评估、跳槽路线 | 拿到 offer / 谈薪前 |

五个技能共享同一个**案例文件夹**（你的个人档案 + 知识库），上下文不断，越用越懂你。

## 支持哪些转行方向

**AI 运营方向**（✅ 最完善，第一个样板）
- AI 产品运营 / AIGC 内容运营 / 增长运营 / FDE

**其他方向**（📋 按需扩展，每次服务用户时自然生长）
- AI 产品经理 / 半导体 AE / 数据分析 / 更多方向…

**扩展新方向的方法**：先扒 15 个 JD，再生成对应的学习计划、项目库、面试题。通用方法论和工具直接复用，不用从零开始。

> 只要方法正确，就没有转不了的行。方向只是知识内容不同，底层方法论是通的。

## 核心原则（写死在每个技能里）

1. **不编造**：所有数据实时联网搜索并附来源；查不到就说查不到。**宁可不给，不给错的**——给错一次，公信力归零。
2. **JD 驱动**：先做市场调研再出方案，学习计划和简历都对着真实 JD 来。
3. **AI 只是工具**：AI 负责提效和说真话，跑调研、学习、面试这些执行全靠你自己。
4. **全大白话**：对话和文档不堆术语，英文只保留在文件名上。
5. **知情决策**：不替用户做决定，把风险和真相摆透，让用户自己选。
6. **不拒绝服务**：用户坚持己见时，做"知情确认"而不是甩手不管。

## 飞轮：越用越准

这个技能包不是一次性的——每服务一个用户，知识库就厚一分：

```
用户使用 → 产生真实案例 + badcase
        ↓
脱敏后沉淀进知识库
        ↓
下一个用户来时，输出更准、更全
        ↓
（飞轮加速）
```

- 新行业的迁移经验 → 补充通用方法论
- 新岗位的知识和面试题 → 扩展对应方向知识库
- 新技术栈的学习路径 → 补充技术栈层
- 每次踩的坑 → 进错题本，下次不犯

## 质量保障（3 层 Harness）

为了防止 AI 乱回答，每个 skill 都有 3 层质量校验：

1. **输出自检清单**：每个 skill 输出前必须过 checklist，不通过就自己改
2. **防幻觉铁律**：全局共享的真实性规则，事实必须有来源
3. **Badcase 追踪机制**：每次发现错误都记录、归因、修复、验证，不重复踩坑

## 快速开始

1. 把本仓库克隆或下载到本地
2. 将 `skills/` 下的技能文件夹复制到你 AI 工具的 skills 目录（如 TRAE 的 `.trae/skills/`）
3. 把 `shared/` 和 `assets/` 放在技能可访问的位置（详见 [安装文档](docs/install.md)）
4. 对 AI 说"我想转行"，或直接看 [首次使用指南](docs/first-use-guide.md)

## 目录结构

```
Profession-ez/
├── skills/          # 五个技能（每个含 SKILL.md 主文件 + references 细则）
├── shared/          # 共享规范：数据层、开机引导、防幻觉规则、归档清单
├── assets/templates/# 案例文件夹模板 + 知识库模板（新用户复制一份用）
├── scripts/         # 确定性计算小工具（到手工资、JD 关键词、岗位匹配打分、简历提取）
├── docs/            # 安装、使用、安全、常见问题
└── examples/        # 种子案例（作者真实转行经历，已脱敏）
```

## 数据与隐私

- 你的案例数据（简历、薪资、档案）只存在**你自己的案例文件夹**里，不会被上传
- 本仓库不包含任何真实用户数据，种子案例已脱敏
- 详见 [安全与隐私说明](docs/safety.md)
