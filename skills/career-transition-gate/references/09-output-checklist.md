# 转行门 · 输出自检清单

> 每次输出转行规划前，逐条核对。不通过的项目，必须回去改，改完再输出。
> 这是质量保障的第一道防线。

---

## 一、流程完整性检查

- [ ] **信息收集做了吗？**：profile.yaml 里的必填项都齐了吗？缺的有没有问用户？
- [ ] **行业真相报告做了吗？**：有没有用真实数据泼冷水？数据有来源和日期吗？
- [ ] **动机 5 问问完了吗？**：5 个问题都问了吗？判断清楚是逃离型还是追求型了吗？
- [ ] **现实检验作业布置了吗？**：用户知道要去做什么吗？做了防糊弄验证吗？
- [ ] **可行性评估做了吗？**：经济/能力/时间三维都打分了吗？
- [ ] **JD 市场调研做了吗？**：至少 15 个 JD 吗？是近 30 天的吗？多平台的吗？
- [ ] **调研结果给用户看过了吗？**：用户确认方向和预期了吗？

> ⚠️ 以上有任何一项没做，就不能出最终规划。缺什么补什么。

---

## 二、学习计划质量检查

- [ ] **JD 驱动**：计划里的每个知识点，都能在 JD 调研里找到依据吗？JD 里不怎么提的，有没有降级或砍掉？
- [ ] **6 维度定制化**：
  - [ ] 目标岗位方向对吗？内容重点对齐了吗？
  - [ ] 旧行业经验迁移做了吗？有迁移清单和转化话术吗？
  - [ ] 起点和用户基础匹配吗？不会太简单也不会太难吗？
  - [ ] 内容量和用户时间匹配吗？每天能完成吗？
  - [ ] 符合用户的学习风格吗？
  - [ ] 节奏和转行状态（在职/裸辞）匹配吗？
- [ ] **颗粒度够细**：
  - [ ] 是按周/天拆的，不是"学 XX"一句话完事
  - [ ] 每个知识点有推荐资源吗？
  - [ ] 每个阶段有验收标准吗？（可操作、可量化）
- [ ] **有产出物**：每个阶段结束都有明确的产出物吗？不是"学完了"，是"做出了什么"
- [ ] **不编造**：推荐的课程/资源是真实存在的吗？不确定的有没有说"搜 XX 关键词"？
- [ ] **不画饼**：有没有承诺"学完就能就业""保证拿 offer"这类话？

---

## 三、项目设计质量检查

- [ ] **和目标岗位匹配**：项目能证明目标岗位需要的核心能力吗？
- [ ] **结合旧行业**：有没有利用用户的旧行业背景做差异化项目？
- [ ] **难度合适**：
  - [ ] 和用户基础匹配吗？不会太难做不出来？
  - [ ] 和可用时间匹配吗？
- [ ] **可落地**：
  - [ ] 步骤清晰吗？用户知道每一步做什么吗？
  - [ ] 需要的工具都是免费或容易获取的吗？
  - [ ] 交付物清单明确吗？（checkbox 形式，做完一个勾一个）
- [ ] **有简历价值**：
  - [ ] 每个项目都有简历 bullet 模板吗？
  - [ ] 每个项目都有 STAR 面试话术吗？
  - [ ] bullet 里有数据位置吗？

---

## 四、真实性检查

- [ ] **所有事实都有依据吗？**：行业数据、薪资范围、岗位要求，都来自 JD 调研或实时搜索吗？
- [ ] **标注来源了吗？**：关键数据有没有说"数据来自 XX 平台，XX 时间"？
- [ ] **没有编造吗？**：
  - [ ] 没有编造公司名、产品名、课程名
  - [ ] 没有编造薪资数据
  - [ ] 没有编造不存在的工具或资源
- [ ] **推断标注了吗？**：分析和建议里，哪些是事实、哪些是推断，说清楚了吗？

---

## 五、体验检查

- [ ] **用户能看懂吗？**：用的是普通人能听懂的语言吗？行业黑话有解释吗？
- [ ] **结构清晰吗？**：有标题、有分段、有重点标记吗？不是一大坨文字
- [ ] **预期管理到位吗？**：
  - [ ] 有没有说清"这是路线图，不是保证书"
  - [ ] 有没有说清转行的难度和风险
  - [ ] 有没有说清第一份工作大概率是跳板
- [ ] **有鼓励但不灌鸡汤**：结尾有打气的话吗？是真实的鼓励还是空洞的鸡汤？

---

## 六、数据归档检查

- [ ] **profile.yaml 更新了吗？**：收集到的信息都写进去了吗？
- [ ] **transition-plan.md 写了吗？**：完整的转行规划
- [ ] **jd-research-*.md 存档了吗？**：JD 调研报告单独存了吗？
- [ ] **target-roles.csv 更新了吗？**：目标岗位清单
- [ ] **experience-assets.md 和 strengths.md 更新了吗？**：经历资产和优势清单
- [ ] **project-log.md 更新了吗？**：项目规划记录
- [ ] **有价值的内容进知识库了吗？**：脱敏后有通用价值的，补充进知识库了吗？

---

## 检查不通过怎么办

1. 缺什么补什么，不要硬输出
2. 拿不准的就问用户，不要靠猜
3. 宁可慢一点，也不要输出有问题的内容——坏输出比没输出危害大
