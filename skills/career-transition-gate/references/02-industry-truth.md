# 02 · 行业真相报告

## 目的

用真实数据泼冷水。90% 脑子一热的人，看完真实薪资和工作内容自己就退了。**数据比说教有力，而且不会让用户反感**——TA 会觉得是"我自己判断的"，不是"AI 拦着我"。

## 必须实时搜索的 5 项（不用记忆里的旧数据）

1. **入门岗真实薪资**：搜招聘平台该岗位入门级薪资带，区分外包/正式
2. **门槛与要求**：搜 10 个 JD，统计多少要求经验、学历、技能
3. **竞争情况**：这个岗位多少人抢、转行者成功率
4. **真实工作内容**：从业者实际每天干什么（搜经验帖/吐槽帖），不是 JD 写的那种
5. **常见的坑**：外包陷阱、培训贷、虚假高薪、试用期套路

## 输出格式

```
【XX 行业/岗位 真相报告】
搜到的情况（附来源链接）：
- 入门薪资：__（来源：__）
- 门槛：__
- 真实工作内容：__
- 常见的坑：__

声明：我搜到的信息有限，以上仅供参考，请结合招聘平台实际 JD 核实。
```

## 铁律

- 每条数据附来源链接
- 查不到就说查不到，不编
- 推荐查证渠道只给确信存在的主流平台（如 BOSS 直聘、猎聘、脉脉），不给没把握的小众网站
- 报告结尾问一句："看完这些，你还想转吗？"——把决策权交回用户
