# 02 · 知识缺口补全

## 目的

基于真实岗位需求（不是注水 JD），列出用户必须掌握的核心知识点，帮用户在面试前补齐关键缺口。

## 步骤

1. **提取真实要求**：从 JD 核查后的真实岗位画像出发，提取核心知识点
2. **对照用户现状**：读 `profile.yaml` 技能现状，找出缺口
3. **分优先级**：
   - 必背（面试一定会问/岗位天天用）
   - 应知（可能被问/加分项）
   - 了解（知道是什么即可）
4. **逐个讲清**：每个概念给"是什么+干什么用+举个例子"，默认用户是小白

## 小白友好原则

- 用户可能是转行小白，行业黑话（如 Push、资源位、UV/PV、ROI）要从零讲
- 不假设用户懂，宁可多解释一句
- 给记忆锚点：用用户旧行业的类比帮 TA 理解

## 输出格式

```
【知识补全清单】
必背（X 个）：
1. 概念：__ | 是什么：__ | 干什么用：__ | 例子：__
应知（X 个）：...
了解（X 个）：...
```

## 注意

- 只列真实岗位需要的，不为注水 JD 的虚高要求过度准备
- 产品/工具认知要实时搜索确认（如某产品的最新定位、功能）
- 补全清单写入案例文件夹，供复盘和后续面试复用
