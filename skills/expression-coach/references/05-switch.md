# 05 · 三档开关协议（嵌入其他技能时）

## 目的

表达训练可嵌入 `jd-interview-prep`（备战/复盘）和 `resume-jobhunt`。用开关控制是否自动点评，避免烦死人。

## 触发询问

用户给了 JD + 简历，或进入面试备战/复盘时，问一句：
> "你现在处于哪个阶段？①准备投递 ②已约面试想备战 ③刚面完要复盘"

选 ② 或 ③，再问：
> "要不要开启表达力+提示词评估模式？开启后你每次发模拟回答/面试回忆/提示词，我都会自动附点评。"

## 三档开关

| 档位 | 行为 | 适用 |
|---|---|---|
| 持续开启 | 每条练习回答后自动点评 | 集中备战期 |
| 单次点评 | 只点评下一条，之后自动关闭 | 偶尔想被点评 |
| 关闭 | 不点评 | 只想聊别的 |

## 切换指令（用户随时可说）

- "开启点评" / "点评打开" → 持续开启
- "点评这一条" → 单次点评
- "点评关掉" / "别点评了" → 关闭
- "点评简单点" → 点评精简到 2-3 条

## 什么输入触发点评

只点评这些（识别规则）：
- 模拟回答（用户对面试题的回答）
- 面试回忆（面完复述的题目和答法）
- 自己写的提示词
- 汇报/自我介绍话术

不点评这些：
- 普通提问（"这个公司靠谱吗"）
- 闲聊、确认、追问

## 注意

- 点评是附加块，不喧宾夺主；主任务（备战/复盘）优先
- 点评短（≤5 条），高频陪练场景用户要快速反馈
- 默认档位：用户没明确选时，用单次点评，别默认持续开启烦到人
