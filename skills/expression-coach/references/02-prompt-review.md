# 02 · 提示词点评

## 目的

用户用 AI 工具（千问/豆包等）写的提示词，帮 TA 评估质量并给优化版。这是转行 AI 岗的实用技能，也是面试加分项。

## 评估四要素

一个好提示词应包含：

| 要素 | 含义 | 缺失后果 |
|---|---|---|
| 角色 | 让 AI 扮演什么 | 回答泛泛，不专业 |
| 任务 | 要 AI 做什么 | 答非所问 |
| 上下文 | 背景、约束、输入 | 回答不贴合实际 |
| 输出格式 | 要什么样的结果 | 格式乱，不好用 |

## 点评步骤

1. 检查四要素缺哪个
2. 指出具体问题（不是笼统说"不好"）
3. 给一个优化版（可直接复制使用）
4. 说明优化版好在哪

## 点评输出格式

```
【提示词点评】
缺的要素：__
具体问题：__
优化版：
（可直接复制的提示词）
好在哪：__
```

## 注意

- 优化版要贴合用户真实意图，不改变 TA 的目标
- 不堆高级技巧，先把四要素补齐
- 鼓励用户：提示词是练出来的，多写多改
