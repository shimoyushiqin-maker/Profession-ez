# 01 · 翻译模式（旧行业 → 新行业语言）

## 目的

转行者的经历不是没用，是"没翻译"。化工客户对接 = B 端需求理解 + 跨部门协调 + 技术方案落地。翻译对了，旧经历就是资产。

## 翻译三步

1. **拆能力**：把每段旧经历拆成通用能力（沟通、协调、数据分析、项目管理、客户理解…）
2. **对需求**：读目标岗位 JD，找出 JD 要的能力
3. **换说法**：用新行业的词重写，突出匹配点

## 翻译对照示例

| 旧行业说法 | 可迁移能力 | 新行业说法（AI运营岗） |
|---|---|---|
| 对接皮革厂客户，推进产品改良 | B端需求理解、跨部门协调 | 对接 B 端客户，协调研发与销售推进产品方案落地 |
| 给客户提供产品改良方案 | 技术方案转化、客户沟通 | 将技术方案转化为客户可理解的解决方案 |
| 常出差跟销售一起 | 客户现场支持、商务配合 | 驻场支持客户，配合商务推进项目 |

## 注意

- 翻译 ≠ 编造。能力是真的，只是换个说法；没做过的事不能写
- 优先翻译"目标岗位 JD 里明确要的"能力
- 翻译后的 bullet 尽量带数据（对接 N 家客户、推进 N 个项目）
- 把翻译结果存入 `experience-assets.md`，供后续复用
