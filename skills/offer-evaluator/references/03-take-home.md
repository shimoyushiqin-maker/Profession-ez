# 03 · 真实到手测算

## 目的

名义工资 ≠ 到手工资。试用期打折、五险一金基数、个税、拆绩效，都会让到手缩水。必须算清真实到手，用户才能判断够不够生存+攒钱。

## 强制用脚本

到手测算用 `scripts/salary_calculator.py`，不心算。心算容易错，错了就是误导用户的薪资决策。

## 需要用户提供的输入

1. 名义月薪（转正）
2. 试用期打几折、试用期多久
3. 五险一金：按什么基数交（全额/最低）、个人比例
4. 是否拆绩效、绩效占比
5. 有没有补贴

## 测算输出

```
【真实到手测算】
转正：名义 __ → 到手约 __（扣五险一金 __、个税 __）
试用期：名义 __ → 到手约 __
每月生存成本估算：__（房租+吃饭+通勤，按城市）
每月能攒：__
```

## 判断标准

- 到手 - 生存成本 = 每月能攒的钱
- 能攒 > 0 且符合用户攒钱目标 → 经济上可行
- 到手连生存都紧 → 提醒用户慎重，除非当短期跳板

## 隐形亏损提醒

- 五险一金按最低基数交 = 每月公积金账户少进账几百，是隐形亏损
- 拆绩效 = 绩效部分可能被扣，不稳定
- 这些要在评估里明确告诉用户

## 铁律

- 测算用脚本，不心算
- 生存成本按用户城市估算，不确定就问用户
- 不给精确到个位的假精确，用"约"
