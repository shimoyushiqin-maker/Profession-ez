# Offer评估 · 输出自检清单

> 每次输出 Offer 评估前，逐条核对。不通过的项目，必须回去改，改完再输出。

---

## 一、信息完整性检查

- [ ] **薪资信息全吗**：
  - [ ] 税前月薪多少？
  - [ ] 试用期打几折？试用期多久？
  - [ ] 五险一金比例？基数是全额还是最低？
  - [ ] 年终奖 / 绩效奖 / 其他补贴？
- [ ] **岗位信息全吗**：
  - [ ] 岗位名称、具体做什么？
  - [ ] 是正式还是外包？派驻哪家公司？
  - [ ] 团队规模、汇报对象？
- [ ] **公司信息全吗**：公司做什么的、规模、行业地位？
- [ ] **其他信息**：
  - [ ] 通勤时间？
  - [ ] 加班情况？
  - [ ] 入职时间要求？

> 信息不全就问用户要，不要靠猜。猜出来的评估没有意义。

---

## 二、到手计算检查

- [ ] **用脚本算了吗**：真实到手金额是用 `scripts/salary_calculator.py` 算的吗？
- [ ] **参数对吗**：
  - [ ] 社保比例、公积金比例对吗？
  - [ ] 缴费基数比例对吗？（最低基数的话一定要说明）
  - [ ] 试用期折扣对吗？
- [ ] **结果清晰吗**：
  - [ ] 转正到手多少？
  - [ ] 试用期到手多少？
  - [ ] 每个月扣多少社保公积金个税？
- [ ] **隐形亏损说了吗**：按最低基数交的话，隐形亏损大概多少？

---

## 三、六维打分检查

- [ ] **六个维度都打了吗**：薪资 / 成长 / 内容 / 稳定 / 通勤 / 匹配
- [ ] **打分有依据吗**：每个维度的分数，都有理由吗？不是凭感觉瞎打
- [ ] **结合用户情况**：
  - [ ] 薪资维度——和用户的薪资底线比怎么样？
  - [ ] 成长维度——用户想转行，这个 offer 能不能学到东西？
  - [ ] 匹配度——和用户的转行目标一致吗？
- [ ] **客观中立**：没有因为想让用户接/不接而故意打高/打低分

---

## 四、决策建议检查

- [ ] **决策结论明确吗**：接 / 不接 / 再谈谈，三选一，不要模棱两可
- [ ] **理由充分吗**：为什么是这个决策？3 条以上核心理由
- [ ] **结合用户处境**：
  - [ ] 有存款吗？没存款的话生存优先
  - [ ] 是在职还是裸辞？心态压力不同
  - [ ] 转行目标是什么？这个 offer 是跳板还是终点？
- [ ] **不站着说话不腰疼**：
  - [ ] 不会因为"外包不好"就直接让用户拒——要考虑用户的生存压力
  - [ ] 不会因为"工资高"就直接让用户接——也要看成长和匹配度
  - [ ] 不会说"这点钱也去？"这种话

---

## 五、跳槽路线检查

- [ ] **有路径吗**：接了这个 offer 之后，下一步往哪跳？
- [ ] **路径现实吗**：
  - [ ] 每一跳的薪资范围是真实的吗？
  - [ ] 时间预期合理吗？（通常 12-18 个月一跳）
  - [ ] 每一跳"靠什么跳"说清了吗？（带走什么履历/数据/作品）
- [ ] **不画大饼**：没有承诺"一定能跳到多少K"，给的是路径不是保证
- [ ] **有可操作性**：用户知道接下来 12 个月要攒什么弹药吗？

---

## 六、谈薪建议检查（如果适用）

- [ ] **谈薪空间判断**：这个 offer 有谈薪空间吗？
- [ ] **谈多少合适**：建议谈到多少？有依据吗？
- [ ] **谈薪话术**：给了具体的谈薪话术吗？不是空泛的"你可以谈谈"
- [ ] **风险提示**：谈薪可能有什么风险？怎么规避？

---

## 七、真实性检查

- [ ] **薪资数据真实吗**：参考的行业薪资数据有来源吗？
- [ ] **跳槽路线真实吗**：市场上真的有这个路径吗？不是凭空想的
- [ ] **没有夸大**：没有为了让用户接而夸大成长空间
- [ ] **没有贬低**：没有为了让用户拒而贬低这个 offer

---

## 八、数据归档检查

- [ ] **offer-review.md 写了吗**：完整的评估报告存档了吗？
- [ ] **review-log.md 更新了吗**：复盘日志更新了吗？
- [ ] **行业数据入知识库了吗**：有价值的薪资数据、行业信息，脱敏后补充进知识库了吗？

---

## 红线

- ❌ 不能替用户做决定——分析和建议是你的，决策是用户的
- ❌ 不能保证"接了一定好""拒了一定有更好的"——未来不确定，只能给概率和分析
- ❌ 不能站着说话不腰疼——要站在转行者的处境考虑，生存压力是真实的
- ❌ 不能算错钱——到手金额必须用脚本算，不能心算
