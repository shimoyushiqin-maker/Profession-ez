# Profession-ez 宣传推广方案

> 核心认知：**你卖的不是一个 skill，而是"普通人也能转行 AI"的希望和方法。**
> skill 是方法的载体，你的真实故事才是流量的来源。

---

## 一、爆款底层逻辑（为什么爆）

通过分析小红书、抖音上转行/求职/AI工具类爆款内容，爆的原因只有三个：

1. **真实感**：用户对"广告感"极度敏感。真实的踩坑、真实的数字、真实的情绪，比精美包装管用 10 倍。"说缺点"反而增加可信度。
2. **身份认同**：当用户看到"专升本""化工转行""零互联网经验""社恐表达差"这些标签和自己高度吻合时，会产生"这说的就是我"的感觉。
3. **可复制的方法**：光有故事不够，要给"我也能照着做"的具体方法。故事负责传播，方法负责收藏和关注。

**爆款公式 = 真实故事（传播）+ 精准痛点（认同）+ 可复制方法（收藏）+ 互动引导（评论）**

## 二、你的人设定位

### 账号人设（一句话）

> "专升本、化工行业转行 AI 的普通人，把自己踩过的坑和摸出的路，做成了一套开源的转行陪跑工具。"

### 人设三要素

| 要素 | 你的素材 | 为什么有效 |
|---|---|---|
| 起点低（反差） | 专升本、化工传统行业、Python/SQL 只能看懂 | 降低受众心理门槛："他这样都行，我也行" |
| 真实踩坑（信任） | 试岗两天被劝退、汇报紧张没逻辑、自我矮化表达 | 失败者复盘比成功者炫耀更有传播力 |
| 有结果（希望） | 拿到 AI 公司 offer、做出开源技能包 | 给受众"跟着他能成"的信心 |

### 账号设置建议

- **昵称**：带身份标签，如"阿墨转行记""化工转AI的阿墨""转行陪跑员阿墨"
- **简介**：`专升本→化工→AI | 把转行踩的坑做成开源工具 | 陪每个普通人转行不踩坑 | 工具在置顶`
- **头像**：真人（侧脸/背影也行），不想出镜就用简洁文字头像
- **背景图**：放 GitHub 仓库二维码或"转行五步法"示意图

## 三、小红书玩法（主战场，图文为主）

### 3.1 为什么先做小红书

- 转行/求职人群和小红书用户高度重合（20-30岁、焦虑、爱搜攻略）
- 图文门槛低，不用露脸、不用剪辑
- 收藏属性强，干货笔记有长尾流量（半年后还在被搜到）
- 小红书是"搜索+推荐"双引擎，SEO 布局好能持续获客

### 3.2 封面形式（3 选 1，保持统一）

**形式 A：大字报备忘录风（最推荐起步用）**
- 手机备忘录截图风格，黑底白字或白底黑字
- 大字标题占屏幕 1/2，加 emoji
- 例：`专升本化工转AI，我把转行做成了开源工具🔥`

**形式 B：对比图风**
- 左右分栏：转行前 vs 转行后 / 错误简历 vs 改后简历
- 视觉冲击强，点击率高

**形式 C：干货清单风**
- 纯色背景 + 序号清单 + 关键词高亮
- 例：`转行AI前必看的6个坑｜第3个我差点踩`

> 封面文字不超过 3 个核心信息点，3:4 竖图，风格全账号统一。

### 3.3 标题模板（直接套用）

**故事型（最容易爆）：**
- `专升本化工转AI，试岗2天被劝退，我做错了什么`
- `28岁化工转行AI，拿到offer那天我哭了`
- `零互联网经验，我是怎么转行AI运营的（全流程）`

**避坑型（收藏率最高）：**
- `转行AI前不看这6个坑，少说多走2年弯路`
- `简历里这4句话，HR看一眼就划走（附改法）`
- `试岗被劝退才懂：汇报没逻辑比没能力更致命`

**方法型（引流到skill）：**
- `我把转行AI的全流程，做成了一个免费开源工具`
- `转行不知道从哪开始？我做了个AI陪跑技能包`
- `用AI帮你改简历/算到手工资/模拟面试，全开源`

**反认知型（评论区最火）：**
- `别再裸辞转行了，存款不够6个月真的会死`
- `程序员都在失业，我们普通人转行AI凭什么？`
- `外包岗很脏简历？待1年是镀金，待3年才生锈`

### 3.4 正文结构（黄金三段式）

```
【开头 2-3 行】痛点共鸣 / 故事场景，用"你"开头
  例："你是不是也想转行AI，但不知道从哪开始？
       我是专升本、化工行业出来的，3个月前也这么想。"

【中间 3-5 个小节】干货分点，每点不超过3行
  - 用 ➊➋➌ 或 ▪️ 分隔
  - 每段不超过4行（手机阅读友好）
  - 重点加粗，口语化，像跟朋友聊天

【结尾 2-3 行】互动引导 + 软引流
  例："我把这套转行方法做成了开源技能包，
       简历优化/面试模拟/offer评估都能用，
       需要的评论区扣【转行】，我发你。"
```

## 四、抖音玩法（视频，第二阶段做）

### 4.1 推荐形式（按起号难度排序）

| 形式 | 难度 | 适合内容 | 建议 |
|---|---|---|---|
| 图文轮播 | ★ | 避坑清单、工具清单 | **最先做**，把小红书笔记直接转 |
| 录屏+配音 | ★★ | skill演示、AI工具教程 | 展示"AI帮你改简历"的过程 |
| 口播出镜 | ★★★ | 转行故事、观点输出 | 涨粉最快但需要表达力 |

> 建议路径：**图文轮播起号 → 录屏演示建立信任 → 口播故事破圈**。你的表达训练 skill 正好能帮自己练口播。

### 4.2 前3秒钩子话术（直接用）

**故事型：**
- "专升本、化工行业、零互联网经验，我转行AI了。"
- "试岗两天就被劝退，那天我在电梯里站了十分钟。"

**反认知型：**
- "90%的人转行第一步就错了，难怪简历石沉大海。"
- "程序员都在失业，你一个外行凭什么转行AI？"

**利益型：**
- "我做了个免费AI工具，帮你从转行决策一路陪到拿offer。"
- "简历投了100份没回音？用这个方法改完一周4个面试。"

### 4.3 视频结构（30-50秒）

```
0-3秒   强钩子（上面话术）
3-15秒  讲痛点/讲结果（"我之前也是这样……"）
15-40秒 给方法/演示工具（录屏展示skill怎么用）
40-50秒 引导互动（"工具开源免费，评论区扣1发你"）
```

### 4.4 抖音选题（和小红书复用，一鱼多吃）

同一份内容，小红书发图文，抖音发图文轮播+录屏。重点选题：
- 转行故事（口播）
- skill 实操录屏（"看AI怎么3分钟改完简历"）
- 避坑清单（图文轮播）

## 五、引流路径（怎么把人引到 GitHub）

### 核心原则
**不要在正文/视频里直接放 GitHub 链接**（平台限流，小红书对站外链接管控严）。用"评论区扣关键词 → 私信发链接"的方式。

### 引流漏斗

```
爆款内容（故事/避坑）
    ↓ 评论区引导"扣【转行】"
私信自动/手动回复
    ↓ 发 GitHub 链接 + 一句使用说明
GitHub 仓库
    ↓ README 引导
用户下载使用 → 觉得好用回来点赞收藏
    ↓
形成"内容涨粉 → 工具获客 → 口碑反哺"飞轮
```

### 各平台具体操作

**小红书：**
- 正文结尾："工具开源免费，需要的评论区扣【转行】，我挨个发"
- 评论区置顶："扣关键词的姐妹看私信哈～工具在GitHub，直接下载就能用"
- 主页简介："转行工具在置顶笔记🔗"（置顶笔记里放链接截图引导）

**抖音：**
- 视频结尾："工具在评论区置顶"
- 评论区置顶："GitHub搜 Profession-ez，或者主页粉丝群拿链接"
- 主页简介引导加粉丝群

**B 站 / 知乎（长尾补充）：**
- B站发录屏教程，简介放 GitHub 链接（B站不限制）
- 知乎回答"如何转行AI运营""转行AI需要学什么"等问题，文末带工具

### 私信回复模板

## 七、badcase 归因 = 最好的内容素材

你提到要"不断迭代优化 badcase 归因"——这不仅是在优化 skill，**每一个 badcase 都是一条爆款内容的原料**：

| skill 里的 badcase | 转化成的内容 |
|---|---|
| 用户被"培训贷"坑了 | 《转行AI遇到让你先交钱的，快跑》 |
| 用户简历造假被背调刷了 | 《简历千万别编，背调出来全完了》 |
| 用户裸辞后存款耗尽 | 《裸辞转行3个月，我差点活不下去》 |
| 用户面试紧张说不出话 | 《面试脑子空白？这个框架救了我》 |
| 用户接了外包以为是正式 | 《offer上这个词不看清，入职就懵》 |

**操作方式**：每次帮用户解决一个典型问题，脱敏后就是一条"真实案例+方法"的笔记。真实案例永远比编造的干货有说服力。

## 八、注意事项

### 小红书违禁词（会被限流）
- 绝对化用词：最、第一、首个、极、100%、保证
- 明示站外链接、引流微信/QQ（用"主页""私信"替代）
- 医疗/金融承诺类词汇
- 参考：CSDN 上有 skill 作者专门内置了小红书违禁词规则，发布前自查

### 内容红线
- **不承诺结果**：不说"保证转行成功""包拿offer"，说"提高概率""陪你少走弯路"
- **不贩卖焦虑过度**：可以泼冷水，但结尾要给希望和方法
- **真实第一**：数据、经历必须真实，不编造成果
- **脱敏**：分享案例必须改公司名、薪资、城市（和 skill 的脱敏原则一致）

### 心态
- 前 10 篇没流量很正常，爆款是测出来的不是憋出来的
- 不要等"完美"再发，先发再迭代
- 评论区每条都回，前期粉丝信任比数量重要

## 九、一句话总结

> **用你的真实转行故事吸引同频的人，用 skill 里的方法帮他们解决问题，用开源免费降低使用门槛，用 badcase 持续产出真实内容。**
>
> 你不是在卖工具，你是在告诉每个想转行的普通人："我这样的都行，你也可以。"
