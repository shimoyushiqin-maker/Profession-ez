# 使用指南

## 五个技能怎么用

| 你想干什么 | 对 AI 说 | 用哪个技能 |
|---|---|---|
| 纠结要不要转行 | "我想转行做XX，帮我分析" | 转行门 |
| 改简历 | "帮我改简历" + 发简历文件 | 简历优化 |
| 准备面试 | "我明天面试，帮我备战" + 发JD | JD备战 |
| 练表达 | "帮我点评这段回答" | 表达训练 |
| 评估offer | "我拿到offer了，帮我评估" | Offer评估 |

## 推荐流程

```
转行门（该不该转+学什么+做项目）
   ↓
简历优化（翻译经历+投递）
   ↓
JD备战（核查+补知识+模拟）
   ↓
表达训练（贯穿全程，随时练）
   ↓
Offer评估（谈薪+决策）
```

任何一步都能单独用，不必从头走。

## 案例文件夹（你的档案）

第一次用，AI 会建一个案例文件夹存你的信息：
- 简历、经历、优势、转行规划、面试记录、offer评估都在里面
- 下次用，AI 会读档案接着聊，不用重新介绍自己
- 这些数据只在你本地，不会上传

## 知识库（越用越聪明）

- 真实面试题、行业薪资、错题本会沉淀进知识库
- 你每次面试复盘、每次踩坑，都在让知识库变强
- 这就是"飞轮"：用得越多，AI 越懂这个赛道

## 几个提醒

- AI 给的数据会附来源，但信息有限，重要决策请自己再核实
- AI 不替你做决定，把选项和利弊摆给你，你来选
- 执行靠你自己：跑调研、学习、面试，AI 帮不了你跑腿
