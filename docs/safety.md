# 安全与隐私说明

## 你的数据在哪

- 你的案例数据（简历、薪资、档案、面试记录）只存在**你本地的案例文件夹**里
- 本技能包**不收集、不上传、不传输**你的任何数据
- 技能文件本身不含任何真实用户数据

## 仓库里有什么

- 技能规则、模板、脚本、文档
- 一个**已脱敏**的种子案例（姓名、可识别信息已处理）
- 不含任何真实用户的简历、薪资、联系方式

## 你自己要注意的

1. **简历别乱传**：不要把简历传到不明网站、不可信的"代投"服务
2. **身份证扫描件加水印**：入职交材料时，加"仅供XX入职使用"水印
3. **警惕培训贷/交钱入职**：让你先交钱的都是骗局
4. **背调如实**：不编造经历，编造过不了背调，穿帮损失更大

## 贡献者注意

- 提交案例到本仓库必须脱敏（改姓名、去可识别信息）
- 不得提交真实用户的简历、薪资、联系方式
- 详见 CONTRIBUTING.md
