# 归档清单（每个技能结束前必做）

飞轮的棘轮：只进不退。每次服务结束前，对照本清单归档，没归档不算闭环。

## 通用清单（所有技能）

- [ ] `profile.yaml` 是否更新？（阶段、目标、新获得的限制条件）
- [ ] 本次对话是否产生新的**事实**？→ 写入对应案例文件，标注类型和日期
- [ ] 是否产生新的**推断**？→ 写入时明确标 `推断`，不与事实混写
- [ ] `review-log.md` 是否追加本次关键节点总结？

## 各技能专项

### 转行门
- [ ] 行业真相数据 → `knowledge-base/industry-data/`（带来源和日期）
- [ ] 知识点路线、项目安排 → `transition-plan.md`
- [ ] 目标岗位清单（方向/优先级/缺口）→ `target-roles.csv`
- [ ] 用户确认的转行决策 → `profile.yaml` + `review-log.md`

### 简历优化
- [ ] 简历新版本 → `resume_vN.md`（旧版保留）
- [ ] 投递记录 → `application-tracker.csv`
- [ ] 新挖掘的优势 / 素材 → `strengths.md` / `experience-assets.md`

### JD 备战
- [ ] 真实面试题 → `knowledge-base/interview-question-bank/<岗位>.md`
- [ ] 面试复盘（答得好 / 答得差）→ `interview-log.md`
- [ ] 失败 / 减分案例 → `knowledge-base/mistake-book.md`
- [ ] 新发现的表达弱点 → `expression-weaknesses.md`

### 表达训练
- [ ] 新发现的口头禅 / 逻辑毛病 → `expression-weaknesses.md`
- [ ] 打磨好的 STAR 故事 → `interview-story-bank.md`
- [ ] 优化后的提示词范例 → 案例文件夹

### Offer 评估
- [ ] Offer 条款 + 到手测算 + 决策 → `offer-review.md`
- [ ] 新薪资数据点 → `knowledge-base/industry-data/`（带来源和日期）
- [ ] 谈薪经验 / 踩坑 → `knowledge-base/mistake-book.md`

## 归档后

告诉用户一句："这次的关键信息我已经记下来了，下次接着用。"
让用户感知到飞轮在转。
