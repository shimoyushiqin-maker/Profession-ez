# 01 · JD 真实性核查

## 目的

外包岗 JD 常注水：写得丰满（"主导""统筹""全链路"），薪资很低，实际是初级执行岗。帮用户看穿 JD，找到真实业务线和岗位需求，避免预期错位、面试翻车。

## 核查 5 步

1. **薪资-职责匹配判断**：
   - 把 JD 的职责描述和薪资带对比
   - "主导大促""统筹资源位"这类高职责 + 低薪资（如 6-8K）= 严重注水
   - 经验要求与薪资是否匹配（要 3 年经验却只给入门薪资 = 虚高）

2. **真实工作内容还原**：
   - 把注水词汇翻译成真实工作："主导营销会场搭建" → 实际是"页面维护+配置+文案更新"
   - 告诉用户这个薪资级别实际干什么

3. **业务线核查（实时搜索）**：
   - 搜代招公司、用工公司、园区，确认业务线真实存在
   - 搜该公司/该岗位的评价、薪资口碑
   - 附来源，声明信息有限

4. **岗位本质判断**：
   - 是执行岗还是策略岗？是核心业务还是边缘支持？
   - 有没有成长空间（能接触什么、能带走什么）

5. **结论输出**：
   - JD 注水程度：无 / 轻微 / 严重
   - 真实岗位画像：实际干什么、薪资是否合理、值不值得面
   - 面试策略：按真实岗位定位准备，不按注水 JD 准备

## 输出格式

```
【JD 核查结论】
- 注水程度：__
- 真实工作：__
- 薪资判断：__（附来源）
- 值不值得面：__
- 面试定位：按__岗准备，重点展示__
```

## 铁律

- 核查基于搜索到的事实 + 合理性判断，不臆断公司坏话
- 查不到公司信息就说查不到，提醒用户自己核实
- 不因为注水就劝退——注水岗也可能是入行跳板，关键看用户阶段
