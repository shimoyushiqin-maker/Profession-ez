# 05 · 紧急备战包（明天就面）

## 目的

时间紧（几小时内要面）时的急救包。抓重点，不求全。

## 急救顺序（按优先级，时间不够就砍后面的）

1. **JD 快速核查**（5 分钟）：判断真实岗位定位，按真实定位准备，不按注水 JD
2. **自我介绍 60 秒版**：写好逐字稿，大声读 3 遍（读出声，别默念）
3. **必背 5 题**：自我介绍、为什么转行、没经验怎么办、岗位认知、稳定性
4. **万能框架**：结论→因为→举例→收尾，每题 3-4 句，答完就停
5. **紧张急救**：面试前 5 分钟深呼吸（吸4秒-憋4秒-呼6秒）

## 自我介绍 60 秒模板（转行者）

```
我是__，之前在__行业做__，主要负责__（一句可迁移能力）。
最近我在__（为目标岗位做的准备/项目/学习），对__方向有了实际了解。
我看到这个岗位做__，和我想长期发展的方向一致，所以来争取这个机会。
```

## 紧张急救清单

- 语速放到 0.8 倍，慢比快稳
- 每题开头停 1 秒再答，显得稳
- 说散了用"我总结一下"救场，拉回主线
- 不会的题说"这个我了解不深，但我的理解是……"，别硬编
- 答完就停，别画蛇添足加"哈""您不用担心"

## 转行者紧急话术

- 被问没经验：可迁移能力 + 实操项目 + 学习速度，用事实
- 被问稳定性：用事实（上份工作做多久），不过度担保
- 被问薪资：基于核查后的真实薪资带

## 收尾提醒

> "面完立刻把题目发我，不管感觉好坏。复盘是飞轮第一圈。"
