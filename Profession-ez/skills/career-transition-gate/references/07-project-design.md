# 07 · 实操项目设计

## 目的

转行者最大的短板是"没经验"。项目设计就是帮用户**创造经验**——做完一个项目，简历和面试弹药同时到手。

## 核心原则：项目必须能翻译成简历 bullet

学习 → 项目 → 简历 bullet → 面试话术，四件套绑定。做完一个项目，必须产出：
1. 交付物（截图/链接/账号/文档，没有不算完成）
2. 一句可写进简历的 bullet（带数据更好）
3. 一段 STAR 面试话术（情况→任务→行动→结果）

## 选人配项目的步骤

1. 读 `knowledge-base/project-library.md`（项目库）
2. 根据用户的**时间**（每天能投入多少）、**背景**（旧行业能结合什么）、**目标岗位**，从库里选 1-3 个
3. 优先选"能结合旧行业"的项目——这是转行者的差异化（例：化工背景做"化工行业知识库问答"）
4. 难度梯度：先周末级建立信心，再两周级，最后月级

## 项目库维护

- 项目库只收录确信能落地的项目，不编造
- 用户做完新项目、或发现新的可落地项目，补充进项目库（附来源/实践证据）
- 每个项目带难度档：周末级（2-3天）/ 两周级 / 月级

## 输出

- 选中的项目写入 `transition-plan.md` 的项目安排表
- 用户做完后，把交付物和 bullet 记入 `project-log.md`

## 话术

> "你没经验不要紧，咱们做一个出来。这个项目做完，你简历上就多一条真东西，面试也有得讲。"
