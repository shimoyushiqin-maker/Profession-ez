# 06 · 知识点补全（四层知识体系）

## 目的

给转行者一个从零开始、分层递进的知识路线。默认用户是小白，概念要讲清"是什么+干什么用+举个例子"。

## 四层结构（从下往上打）

```
第4层 岗位专项：目标岗位的产品/工具/流程认知
第3层 核心技能：营销运营/投放/数据分析等岗位硬技能
第2层 基础概念：行业黑话与通用概念（如 UV/PV/转化率/ROI/Push）
第1层 工具技能：Excel、AI 工具、Prompt、零代码平台
```

## 生成知识路线的步骤

1. 读用户 `profile.yaml` 的技能现状，判断每层的起点（哪层空白就从哪层补）
2. **实时搜索**目标岗位的真实技能要求（看 10 个 JD 的高频词），不凭记忆
3. 按"先补哪层"排优先级：通常 第2层基础概念 → 第3层核心技能 → 第4层岗位专项
4. 每个知识点给：是什么 / 干什么用 / 举个例子 / 在哪学（只推荐确信存在的主流资源）/ 验证标准

## 学习优先级原则

- 先学**行业黑话**（能听懂、能说出来），再学工具，最后学深层技能
- 很多人一上来啃 Python，其实该先补概念——概念不懂，学了也用不上
- 每个知识点配验证标准："学到什么程度算过关"

## 输出

写入 `transition-plan.md` 的知识路线表，含：层 / 内容 / 优先级 / 预计耗时 / 验证标准。

## 铁律

- 学习资源只推荐确信存在的主流平台，不编造课程名/网址
- 不承诺"学完就能就业"，给的是路线不是保证
