# 01 · 表达评估规则

## 评估三维度

### 1. 结论先行
- 有没有第一句就给结论？还是绕半天才说到点？
- 改法：先说结论，再说原因和例子

### 2. 逻辑结构
- 有没有用"第一/第二/第三"或"结论→因为→举例→收尾"？
- 有没有跑题、发散、绕圈子？
- 改法：套万能框架，每题 3-4 句

### 3. 减分词 / 口头禅
常见减分词及改法：

| 减分词 | 为什么减分 | 改法 |
|---|---|---|
| "也就/只是/学习参考" | 自我矮化 | 删掉，说"上手做了" |
| "您不用担心哈" | 过度担保=心虚 | 用事实说，说完就停 |
| "想看看/学习一下" | 观光客心态 | 改成"想做深/想贡献" |
| 句尾加"哈/呢/吧" | 显得不自信 | 句尾收干净 |
| "可能/也许/大概" | 含糊 | 确定的就说确定，不确定的说"我了解不深" |

## 点评输出格式（≤5 条）

```
【表达点评】
✅ 做得好：__
⚠️ 表达：__
⚠️ 逻辑：__
💡 更好的说法：__
```

## 注意

- 点评要短、要具体、可执行，别写小作文
- 先肯定做得好的，再挑毛病（用户需要信心）
- 把新发现的减分词/毛病写入 `expression-weaknesses.md`
