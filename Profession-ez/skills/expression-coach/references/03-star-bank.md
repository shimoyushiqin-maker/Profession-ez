# 03 · STAR 故事库

## 目的

把用户的真实经历打磨成结构化的面试故事。面试问"举个例子"时，能流畅讲出一个完整、有说服力的故事。

## STAR 四步

| 步骤 | 含义 | 说什么 |
|---|---|---|
| S 情况 | Situation | 当时什么背景、什么处境 |
| T 任务 | Task | 你要解决什么问题、目标是什么 |
| A 行动 | Action | 你具体做了什么（重点，多说） |
| R 结果 | Result | 结果如何，最好带数据 |

## 打磨步骤

1. 从 `experience-assets.md` 和 `project-log.md` 挑经历
2. 按 STAR 四步重写，每步 1-2 句
3. 行动部分突出"我做了什么"，不是"团队做了什么"
4. 结果尽量带数据/可验证的产出
5. 练到能 60 秒内流畅讲完

## 故事库模板

完整模板见 `assets/templates/case/interview-story-bank.md`，包含：
- STAR 四步框架
- 可迁移点（转行专属）
- 证据/作品
- 匹配的岗位关键词
- 可能被追问的点
- 风险措辞（绝对不能说的话）
- 1分钟版 / 3分钟版改进回答

简化版（快速写）：

```
### 故事：[标题]
- 适用问题：（这个问题能用这个故事答）
- S：
- T：
- A：
- R：
- 60秒口语版：（能直接说出口的版本）
```

## 转行者必备故事

至少打磨这几个：
1. 一个"可迁移能力"故事（旧行业经历体现目标岗位能力）
2. 一个"主动学习/做项目"故事（为转行做了什么）
3. 一个"解决问题"故事（遇到困难怎么解决）
4. 一个"为什么转行"的故事（追求型，有准备过程）

## 铁律

- 故事必须基于真实经历，不编造
- 缺数据的标 `needs_proof`，提醒用户补
- 打磨好的故事存入案例文件夹，供面试复用
