# 项目日志

> 记录用户做过的实操项目。每个项目完成后，必须产出"可写进简历的 bullet"。
> 学习 → 项目 → 简历 bullet → 面试话术，四件套绑定。

## 模板

### 项目：[名称]
- **来源**：项目库 / 自定义
- **难度档**：周末级 / 两周级 / 月级
- **开始日期**：
- **完成日期**：
- **做了什么**：（事实描述）
- **交付物**：（截图 / 链接 / 账号 / 文档，必须有，没有不算完成）
- **可写进简历的 bullet**：（一句话，带数据）
- **面试怎么讲**：（STAR 四步：情况→任务→行动→结果）
- **状态**：进行中 / 已完成 / 放弃

---

## 示例（种子案例）

### 项目：AI 标注系统
- **来源**：自定义
- **难度档**：两周级
- **做了什么**：用 AI 工具搭建标注流程，处理数据
- **交付物**：可运行的标注工具 + 处理样例
- **可写进简历的 bullet**：独立搭建 AI 标注系统，完成 XX 条数据标注流程
- **面试怎么讲**：情况(需要标注数据)→任务(没有现成工具)→行动(用AI搭建)→结果(效率提升)
- **状态**：已完成
