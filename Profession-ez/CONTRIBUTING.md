# 贡献指南

感谢你愿意让转行的人少走一步弯路。

## 你可以贡献什么

1. **知识库内容**：真实面试题、行业薪资数据、实操项目、错题本条目
2. **技能改进**：流程优化、话术打磨、规则补漏
3. **文档与示例**：更通俗的说明、更多脱敏案例
4. **Bug 反馈**：在 Issues 里描述问题

## 铁律（不可妥协）

- **不编造**：任何数据、网站、薪资、流程，不确定就不写。宁可不给，不给错的。
- **附来源**：写入知识库的事实性内容必须带来源和日期。
- **全大白话**：面向转行小白，不堆术语。
- **无隐私**：提交的案例必须脱敏（改姓名、公司名可保留行业属性、去掉可识别信息）。

## 文件规范

- 技能主文件 `SKILL.md` 保持精简（只放工作流骨架），细则放 `references/`
- 知识库条目带时间戳：`[2026-09-03]`
- 区分四类信息：事实 / 假设 / 推断 / 用户偏好，不混写

## 提交方式

1. Fork 本仓库
2. 新建分支 `git checkout -b feat/xxx`
3. 提交时说明改了什么、为什么
4. 发起 Pull Request

## 目录约定

```
skills/<skill-name>/SKILL.md        # 技能主文件（薄）
skills/<skill-name>/references/     # 细则（按需加载）
shared/                             # 跨技能共享规范
assets/templates/                   # 模板
examples/                           # 脱敏示例
```
